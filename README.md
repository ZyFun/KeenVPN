Модели и сценарии чтения не устанавливают пакеты и не меняют конфигурацию роутера. Отдельная команда резервного копирования записывает приватные архивы на выбранный USB-раздел, не меняя VPN и не перезапуская службы. Хранилище метаданных менеджера записывает только собственный файл в явно заданный каталог вне каталогов Xray и XKeen; сценарии первичного импорта размещения и присвоения идентификаторов правил пишут только через него. Меню `vpn-menu` и `vpn-setup` показывает результаты сценариев чтения; без подключённых источников шапка главного меню, сводка и быстрая проверка показывают области и проверки «не проверено», а из остальных пунктов выполняется только справка. Успешный результат относится только к выполненным проверкам, а не к готовности VPN или оборудования.

## Запуск

Используйте CPython 3.12 или новее в пределах стабильных выпусков Python 3 на macOS или Linux. Команды выполняются из корня репозитория; сторонние Python-библиотеки не нужны.

Проверка Python:

```sh
python3 -I -S -B scripts/check_python.py
```

Аудит подготовленных локальных файлов Entware:

```sh
python3 -I -S -B scripts/audit_entware.py /path/to/Packages /path/to/ipk-directory
```

Меню просмотра и меню мастера (без флага источники чтения роутера не подключены: шапка, сводка и быстрая проверка показывают области и проверки «не проверено», выполняется также справка; `0` — назад и выход). На роутере флаг `--read-router` подключает [чтение файлов Xray, XKeen, геобаз и процесса Xray](docs/router-sources.md) только для показа:

```sh
python3 -I -S -B scripts/vpn_menu.py
python3 -I -S -B scripts/vpn_menu.py --read-router
python3 -I -S -B scripts/vpn_setup.py
```

## Тесты

```sh
python3 -I -S -B -m unittest discover -s tests -v
```

Тесты используют искусственные данные и [обезличенные фикстуры конфигурации](tests/fixtures/router_snapshot/README.md). Сеть и роутер не требуются.
Для сценариев application доступны общие [тестовые адаптеры в памяти](docs/application.md#тестовые-адаптеры-в-памяти) с настраиваемыми ответами и отказами.
