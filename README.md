# KeenVPN

В репозитории доступны локальные утилиты, разбор ссылок и модели данных на Python:

| Компонент | Назначение |
|---|---|
| [check_python.py](scripts/check_python.py) | Проверка версии интерпретатора, модулей стандартной библиотеки и отдельных API |
| [audit_entware.py](scripts/audit_entware.py) | Статический аудит локального индекса и архивов пакетов Entware |
| [parse_trojan_uri](docs/trojan-uri.md) | Разбор ссылки Trojan + TLS + WebSocket в модель в памяти |
| [Профиль подключения](docs/connection-profile.md) | Стабильный ID, имя, протокол и версия; сборка из готовых параметров или URI через реестр в памяти |
| [Реестр протоколов](docs/protocol-registry.md) | Явный выбор доверенного модуля, метаданные полей и отдельная проверка возможностей движка |
| [Модель маршрутов](docs/routing-model.md) | Условия domain, IP/CIDR, GeoIP/GeoSite, первое совпадение, защита служебных правил, отключение пользовательских и финальное действие DIRECT/VPN/BLOCK |
| [Объяснение маршрута](docs/routing-explanation.md) | Предварительный расчёт по указанным домену/IP, предположениям о DNS и sniffing и управляемому источнику геоданных |
| [Политики Keenetic](docs/keenetic-policies.md) | Модель действующих политик и определение ID по описанию без выбора первой при неоднозначности |
| [Записи устройств Keenetic](docs/keenetic-devices.md) | Выбор отдельной записи по MAC, online/offline/unknown и смена назначения политики с сохранением остальных полей |
| [Режимы сегмента](docs/keenetic-segments.md) | Предварительный расчёт «только выбранные», «весь сегмент», «сегмент кроме исключений» с сохранением индивидуальных назначений |
| [Состояние Keenetic](docs/keenetic-state.md) | Чтение политик, назначений сегментов с запретом доступа, записей устройств, регистрации и runtime из раздельных источников без слияния по имени, IP или интерфейсу |
| [Конфигурация Xray и XKeen](docs/proxy-config.md) | Строгое чтение частей Xray с ревизиями, `xkeen.json`, параметров init как данных и списков портов и адресов; структурная сводка и раздельные факты по порту 53 без доменов, адресов, путей и паролей |
| [Прикладные сценарии](docs/application.md) | Проверка ссылки и сборки профиля, просмотр по ID, проверка возможностей, объяснение маршрута, определение политики, чтение состояния Keenetic и конфигурации Xray и XKeen через структурированные команды и результаты |

Этот код не устанавливает пакеты, не настраивает VPN и не меняет конфигурацию роутера. Успешный результат относится только к выполненным проверкам или разбору данных, а не к готовности VPN или оборудования.

## Запуск

Используйте CPython 3.12 или новее в пределах стабильных выпусков Python 3 на macOS или Linux. Команды выполняются из корня репозитория; сторонние Python-библиотеки не нужны.

Проверка Python:

```sh
python3 -I -S -B scripts/check_python.py
```

Аудит подготовленных локальных файлов Entware:

```sh
python3 -I -S -B scripts/audit_entware.py /path/to/Packages /path/to/ipk-directory
```

Описание входных данных, проверок и кодов завершения:

- [Диагностика Python](docs/python-runtime.md).
- [Офлайн-аудит пакетов Entware](docs/entware-runtime.md).

## Тесты

```sh
python3 -I -S -B -m unittest discover -s tests -v
```

Тесты используют искусственные данные и [обезличенные фикстуры конфигурации](tests/fixtures/router_snapshot/README.md). Сеть и роутер не требуются.
Для сценариев application доступны общие [тестовые адаптеры в памяти](docs/application.md#тестовые-адаптеры-в-памяти) с настраиваемыми ответами и отказами.

## Безопасность и участие

Не публикуйте пароли, VPN-ссылки, токены, закрытые ключи и реальные приватные конфигурации. Для уязвимостей используйте [приватное сообщение](https://github.com/ZyFun/KeenVPN/security/advisories/new).
