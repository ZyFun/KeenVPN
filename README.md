# KeenVPN

KeenVPN — консольный менеджер на Python для безопасной настройки Xray и XKeen на роутерах Keenetic.

Проект должен упростить подключение VPN, управление правилами маршрутизации и устройствами, диагностику, резервное копирование и восстановление без ручного редактирования конфигурационных файлов.

> [!WARNING]
> Проект находится на этапе подготовки. Рабочего установщика и стабильного выпуска пока нет. Не используйте содержимое репозитория для изменения действующего роутера.

## Проверяемая платформа

Первая версия проектируется и будет проверяться на следующей конфигурации:

- Keenetic KN-1811;
- архитектура `aarch64`;
- KeeneticOS 5.1.4;
- Entware на USB-накопителе с корнем `/opt`;
- Xray и XKeen.

Другие модели, архитектуры и версии нельзя считать поддерживаемыми, пока для них не выполнена отдельная проверка.

## Планируемые возможности первой версии

- мастер установки и подключения к существующей конфигурации;
- импорт Trojan + TLS + WebSocket;
- правила `DIRECT`, `VPN` и `BLOCK` для доменов, IP/CIDR и GeoIP;
- выбор устройств и сегментов сети;
- управление XKeen, автозапуском, fail-open и ограниченным kill-switch;
- черновик, маскированный diff, проверка и подтверждение изменений;
- резервные копии, диагностика и проверяемый откат.

Первая версия будет предоставлять Python CLI с командами `vpn-menu` и `vpn-setup`. Web UI и открытый HTTP API в неё не входят.

## Безопасность

Не публикуйте в Issues, Pull Requests или логах:

- полные VPN-ссылки и пароли;
- закрытые SSH-ключи и токены;
- реальные конфигурации с секретами;
- персональные адреса, домены и сведения о домашней сети.

Уязвимости следует отправлять через [приватную форму GitHub](https://github.com/ZyFun/KeenVPN/security/advisories/new). Подробности приведены в [SECURITY.md](SECURITY.md).
